## Featured Projects

### 🧠 [PromptClarity](https://github.com/FranciscoSousaSilveira/PromptClarity)

A local-first desktop tool that improves prompts before they reach an AI assistant.

It runs entirely on the user's machine, works across applications with a global shortcut, and uses local language models through Ollama. The project focuses on privacy, automation and making AI interaction more effective.

**Highlights:** local AI · desktop automation · Electron · TypeScript · Ollama

### 🍕 [Pizza Radar PT](https://github.com/FranciscoSousaSilveira/pizza-radar-pt)

An aggregator for public pizza promotions in Portugal.

The MVP collects and compares offers from major pizza chains in Lisbon, making it easier to find relevant deals without checking several websites and apps manually.

**Highlights:** web data collection · automation · Python · product thinking

### 🏠 [Rent-Munich](https://github.com/FranciscoSousaSilveira/Rent-Munich)

An automation system for finding suitable accommodation in Munich.

It filters rental listings using budget, housing requirements and public transport travel times, then sends alerts through email and Telegram when a relevant listing is found.

**Highlights:** Google Apps Script · JavaScript · web extraction · APIs · Telegram automation · rule-based filtering
